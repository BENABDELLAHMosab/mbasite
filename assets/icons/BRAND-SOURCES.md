# Icônes de contact

Ressources vérifiées et récupérées le 20 octobre 2026. Les fichiers sont servis localement ; aucun appel à ces services n’est nécessaire pour afficher les icônes.

- `gmail.svg` : fichier publié par Google sur [Google Workspace Help](https://knowledge.workspace.google.com/admin/getting-started/brand-your-internal-communications-with-google-workspace), [SVG source](https://knowledge.workspace.google.com/static/images/icons/product/gmail.svg). Version à dégradés déployée en 2026, conservée sans modification. [Annonce Google](https://workspaceupdates.googleblog.com/2026/05/introducing-fresh-visual-identity-for-Google-Workspace-app-icons.html).
- `whatsapp.svg` : pictogramme SVG vert actuellement publié comme icône du [site officiel WhatsApp](https://www.whatsapp.com/), [SVG source](https://static.whatsapp.net/rsrc.php/y1/r/FJbTMJqMap7.svg), conservé sans modification. [Ressources de marque Meta](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/).
- `fa-linkedin.svg` et `fa-github.svg` : pictogrammes de marque de Font Awesome Free 6.5.1, licence CC BY 4.0, attribution dans `FONT-AWESOME-LICENSE.txt`. Source : [Font Awesome](https://github.com/FortAwesome/Font-Awesome/tree/6.5.1/svgs/brands). LinkedIn est affiché en bleu `#0A66C2` ; GitHub reste noir sur une petite surface blanche pour garder son contraste dans les deux thèmes.

Les marques restent la propriété de leurs titulaires respectifs. Leur présence identifie uniquement les moyens de contact et profils du propriétaire de ce portfolio.
